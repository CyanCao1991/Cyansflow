# HTML 原型标注

把产品经理用 AI 生成的 HTML 原型，加工成一个带「标注层」的新 HTML：重点元素旁有红色编号角标，单击弹出结构化注释卡片，右上角有总开关一键显隐。

## 核心原则

1. **只标重点，不标全部**。不是每个字段/元素都标，由你判断哪些值得标。
2. **只补 HTML 看不出来的信息**。HTML 已经清楚表达的（字段名、字段类型、枚举值、是否必填、按钮文案等）不要重复写。
3. **拿不准就不标**。比如数据来源到底是哪个接口、某个计算规则不确定，宁可不写，也不要编、不要写「待确认」占位。
4. **不破坏原型**。标注层是独立注入的一层，绝不修改原型自身的结构、样式、脚本逻辑。
5. **重复结构只标一行**。表格、列表里同构的多行（如明细行）只标第一行的代表性字段即可，不要每行都标——同样的说明重复 N 遍是噪音。标题写「金额（行小计）」这类，点明它代表的是「这一类」。

## 标注内容分三类（有内容才写，没内容的类省略）

- **数据规范**：数据来源、枚举值、初始值、数字/金额的小数点处理等。可自由发挥。
- **交互表现**：只补充页面上**看不出来**的交互——行为动作、反馈提示、联动表现。明显的交互不写。
- **处理逻辑**：前端校验、后端处理、异常/边界情况。主要说明逻辑。

### 怎么写才到位（实战经验）

- **数据来源要具体到"哪个档案 + 什么状态过滤"**。别只写「来源于供应商」，写「来源：供应商档案中状态为合作中的，过滤掉已停用/已拉黑的」——过滤规则正是页面看不出来、却最值得标的信息。
- **计算字段要给出计算式**。金额、税额、合计这类只读字段，直接写公式（如「采购数量 × 采购单价，四舍五入保留 2 位小数」），并注明保留几位小数、何时重算。
- **联动要写清"触发什么、影响谁"**。如「选供应商后自动带出默认付款方式，可手改」「选『是』时采购仓库置灰」。这是交互表现的主力。
- **校验写明触发时机和提示文案**。如「必填，未选时提交拦截并提示『请选择供应商』」，比单写「必填」有用得多。
- **只读/自动生成的字段值得标**。单号生成规则、默认带出当前登录人、字段只读由系统算——这些光看页面是 readonly 输入框，看不出背后规则。
- 一条说明聚焦一件事，用具体业务语言，不堆形容词。

## 执行步骤

### 1. 读取原型并理解

读用户给的 HTML 文件，理解它是什么业务页面、有哪些字段和可交互元素。

### 2. 挑选要标注的重点元素

通读全部元素，按上面的「核心原则」筛出值得标注的。典型值得标的：
- 下拉/列表/表格——数据来源、过滤规则不明显
- 金额/数量/比率类输入或展示——小数点、计算规则
- 有联动、拉式生成、点击触发后端动作的元素——交互看不出来
- 有校验、有特殊处理逻辑的字段

典型**不值得**标的：纯静态文案、字段名已说明一切且无特殊逻辑的普通输入框、装饰性元素。

表格/列表里同构的多行只标第一行的代表字段，不要逐行标。

### 3. 为每个重点元素想清楚绑定方式（selector）

每条标注要绑定到原型里一个具体元素。**优先**给目标元素加一个 `data-anno="N"` 属性（N 是该标注的序号），再用属性选择器绑定——这样最稳，不受原型 class 变动影响。

- 在原型 HTML 里给目标元素补上 `data-anno="1"`、`data-anno="2"` …（这是对原型唯一允许的、最小的改动；只加属性，不改其它）。
- 对应标注的 `selector` 写 `[data-anno="1"]`。
- 如果不方便加属性，也可用已有的 `#id` 或稳定的 CSS 选择器。

角标按 ANNOTATIONS 数组顺序自动编号（第 1 条显示①、第 2 条显示②…），所以**数组顺序 = 角标编号**，建议按页面从上到下、从左到右排列。

### 4. 生成标注数据

把每条标注组织成下面的结构，填进模板的 `ANNOTATIONS` 数组：

```js
{
  selector: '[data-anno="1"]',   // 绑定的元素
  label: '供应商',                // 卡片标题，通常是字段名
  groups: {                       // 只写有内容的分组
    '数据规范': ['下拉单选，数据来源：已启用的供应商档案', '过滤掉状态为停用 / 已删除的供应商'],
    '交互表现': ['选中后自动带出该供应商的默认结算方式'],
    '处理逻辑': ['必填，未选时点保存提示「请选择供应商」']
  }
}
```

- `groups` 的值可以是字符串数组（多条）或单个字符串。
- 三类的 key 必须是 `数据规范` / `交互表现` / `处理逻辑` 这三个之一，卡片会按固定顺序展示。
- 某类没内容就整个省略该 key。

### 5. 组装输出文件

读取 `assets/annotation-layer.html` 模板，把生成的标注数据填进去，再注入到原型 HTML：

1. 复制原型 HTML 的全部内容。
2. 按第 3 步在需要的元素上加 `data-anno` 属性。
3. 把模板里 `ANNOTATIONS` 数组的占位 `/*__ANNOTATIONS__*/` 替换成你生成的标注对象（逗号分隔）。
4. 把整个标注层代码块（从注释开头到结尾）插入到原型 `</body>` 之前；若原型没有 `</body>`，追加到文件末尾。
5. 写出到新文件，命名为「原文件名_标注.html」，与原文件同目录。**不修改原文件**。

### 6. 回报

简要告诉用户：标了几个重点元素、分别是哪些、输出文件路径。如果有些元素你判断拿不准而故意没标，可一并说明，方便用户补充信息后再标。

## 注意事项

- 标注文字直接写进 `groups`，会作为 HTML 插入卡片，**不要包含会破坏结构的原始尖括号**；需要表达「<」「>」时用「小于/大于」或全角符号。
- 一个元素的说明尽量精炼，一条一句，别堆长段落。
- 若原型是多文件（外链 css/js），标注层是自包含的，不影响；只处理这个 HTML 即可。
